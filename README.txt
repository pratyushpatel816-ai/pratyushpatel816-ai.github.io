Important limits
----------------
No website code, metadata, schema, robots.txt, llms.txt, or sitemap can force
Google, ChatGPT, Claude, Gemini, Grok, DeepSeek, or Perplexity to index, cite,
describe, or rank a site first. These files improve crawl access and clarity;
each search/AI service independently decides what to crawl, index, retrieve,
cite, and rank. Google explicitly states that there is no guaranteed indexing
or first-place ranking, and its AI Search features use the same foundational
SEO practices rather than a special AI-mode trick.

The X account URL was not provided, so no X profile link is fabricated.
The Google verification meta tag is the token visible in the supplied site
source screenshot. If Search Console now displays a different token, replace
the content value in index.html with the current token.
